Registry reference
==================

settlement_source
-----------------

How a contract held to its expiry is settled, by settlement style (REF-20). Phase 1 has a source for PM-settled contracts only; AM-settled contracts are never held to expiration (REF-21).

pm_index_close
~~~~~~~~~~~~~~

Settles PM-settled contracts at intrinsic value against the index close on the settlement date (the vendor's adjusted close on that date). Settlement is a cash flow with no fill-model cost (SPEC-50).

Version: ``1``.
